CHRONICLES - REPLACEABLE MAP ART

Drop transparent PNGs into units, buildings or resources using the paths listed
in ../visuals.json. Missing images keep the existing procedural graphics.

Example: units/industrious_laborer.png replaces the laborer and its work jobs.
Set each entry's size, pivot, hitbox and optional animation frames in visuals.json.
Images can have any source resolution; size controls their displayed game size.

Restart the game after changing files, or use the game's art reload command when
available. No Unreal Editor, recook or recompilation is needed for PNG/JSON changes.

For examples and the field reference, see Docs/ArtReplacement.md in the project.
