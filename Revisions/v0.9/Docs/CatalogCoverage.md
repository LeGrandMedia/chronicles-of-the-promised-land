# v0.4 Catalog Coverage

This guide summarizes the current v0.4 content catalog. The JSON catalog is the source of truth for playable definitions; this document is a human-readable coverage note. Runtime validation is pending.

| Catalog area | Count |
| --- | ---: |
| Units, including heroes, workers, beasts, and ships | 71 |
| Buildings | 17 |
| Upgrade definitions | 58 |
| Factions | 6 |
| Age-choice entries | 36 (two choices for each faction at Ages II, III, and IV) |

The six factions are Nephites, Lamanites, Gadianton, Coriantumr Jaredites, Shiz Jaredites, and House of Laban. Faction-specific roster names and descriptions are stored as display overrides or faction description maps while stable definition IDs remain unchanged.

The catalog includes the Lamanite Rameumptom display name on the existing Temple of the Land, House of Laban’s Great and Spacious Building display name, the Gadianton Secret Combination Lodge, House of Laban Vineyards and Winery, independent Jaredite Curelom/Cumelom/Elephant units, Cement costs, and age-choice hero entries. No Judgment Seat or separate Rameumptom building definition exists. Gadianton has no farm or flock building roster entries.

Important current content rules include Band of Kishkumen raid move targeting the first eligible enemy economic structure in sight without damaging it; Galavant trader rewards; Laban’s Drunken Concubine and building auras; and separate passenger capacities for boats, the chariot, and the elephant. See [Balance v0.4](Balance-v0.4.md) for the specified values.
