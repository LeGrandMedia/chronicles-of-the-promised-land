# Rotated selection in v0.9

GPT-6.2 Sol was recommended and used for the picking changes and regression probe.

An exact click goes to the frontmost hit on the posed 3D model. On a miss, mouse selection tests neighboring visible pixels up to 3 px away for owned mobile units. Touch selection uses the existing touch tolerance against visible model pixels. Right-click context orders keep a 5 px tolerance around visible art, so an empty corner of a bounding box can still be used for a ground order. A nearer entity mesh or raised terrain can block any sampled ray. These changes use the current client snapshot and leave command validation on the server. [Picker source](../Game/Source/Chronicles/RTSScene3D.cpp)

Drag selection clips to the playable viewport and tests projected model triangles where the rectangle crosses a model’s bounds. A rectangle that contains an entire model can accept it without processing every triangle. Owned units take priority over buildings, and group selection can include owned units behind terrain. Shift-click toggles a single entity, and double-click selects matching owned units whose ground positions are on screen. Remembered entities, dead entities and covered HUD click positions are excluded. [Controller source](../Game/Source/Chronicles/RTSController.cpp)

## Verification

`-RTSV09SceneTest` runs 24 selection views at yaw 0°, 45°, 90°, 135°, 180°, 225°, 270° and 315°, each at 0.55×, 1.65× and 4× with camera pan offsets. The fixture checks the engine projection, a laborer overlapping a Seat, a tree, a partly clipped tree at the viewport edge, mouse and touch near misses, right-click edges and blank corners, drag selection, Shift and double-click, fog memory, death and HUD clipping. It uses the controller’s selection methods and the posed meshes. `-RTSInputTest` exercises viewport mouse and keyboard event delivery. On Windows, `-RTSTouchPreview -RTSV09TouchTest` enables the touch layout and exercises touch event delivery through the game’s viewport. [Fixture source](../Game/Source/Chronicles/RTSSceneTests.cpp)

The current Win64 Development package (`CC8D75CD…`) passed 86 scene checks at 1600 × 900, 67 mouse and keyboard checks at both 1600 × 900 and 888 × 500, and 26 Windows touch-preview checks.
