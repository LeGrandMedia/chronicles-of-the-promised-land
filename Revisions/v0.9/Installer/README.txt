CHRONICLES OF THE PROMISED LAND — v0.9

PLAY
Start Chronicles from the Start menu or desktop shortcut. Unreal Editor and
development tools are not required. The installer includes the Windows game
and Epic's runtime prerequisite installer so setup works offline. If Windows
requires a restart to finish installing runtimes, restart and run setup again.

LAN MULTIPLAYER
Use this same v0.9 installer on each Windows PC. One commander chooses Host a
LAN Game. Other commanders join using the host's displayed LAN IPv4 address.
Allow Chronicles on Private networks if Windows Firewall asks. The game uses
UDP port 7777; guest Wi-Fi/client isolation can prevent devices from joining.

USER DATA
Control bindings and other local configuration are saved under
Chronicles\Saved inside the install folder. Uninstall removes installed game
files and shortcuts but preserves files created in Saved; they can be removed
manually if no longer needed.

SUPPORT
This is a Windows x64 build. macOS, Android, and iPhone packages are separate
platform builds and are not included in this installer.
